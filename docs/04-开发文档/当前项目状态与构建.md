## 目录

`src/` 保存扩展代码，`resources/` 保存 Webview 资源，`scripts/` 保存本地测试，`themes/markdown-theme/` 保存 Less 主题及产物，`docs/` 保存维护文档，`release/` 保存历史交付记录与归档。VSIX 输出不应覆盖已有包。

## 构建与测试

在仓库根目录执行：

```zsh
npm ci --no-audit --no-fund
npm --prefix themes/markdown-theme ci --no-audit --no-fund
npm run theme:build
npm run package
npm run test:local
```

`npm run test:local` 使用临时文件与模拟宿主，不启动 IDE，不等于真实窗口验收。测试涉及 Markdown 保真、工具栏存储及布局、主题、表格保存和消息边界。主题目录的说明见 [主题 README](../../themes/markdown-theme/README.md)。

`npm test` 会启动隔离 IDE 窗口，必须事先获得明确授权并通过 `VSCODE_EXECUTABLE_PATH` 指定已有可执行文件。缺省不会自动下载 IDE；不得为了测试而升级、重启、重载或退出用户正在使用的窗口。

使用本机已安装的 `@vscode/vsce` 打包，并核查包内版本、资源与 SHA-256。构建后源码、依赖或资源发生变化时，重新构建及验包；不要把旧包哈希记为新包证据。

## 开发与升级边界

- Markdown 工具栏移动原有节点，固定设置入口；布局存入扩展状态，并只读兼容旧布局设置。扩展状态不会默认跨 IDE 同步。
- 文件保存使用冲突检查和安全写入；复杂 Markdown／XLSX 场景不能因编译成功就判定保真。
- 图片路径必须通过真实路径和可信根检查，KaTeX 资源随包提供。
- 测试和升级过程不自动发布扩展商店、不自动操作用户 IDE；回退说明见 [安装与回退说明](../06-运维与部署/安装与回退说明.md)。
- 上游升级按 [持续维护方案](../06-运维与部署/上游升级与自研差异持续维护方案.md) 固定基线、逐功能复核，并保留已发布个人主干历史。
