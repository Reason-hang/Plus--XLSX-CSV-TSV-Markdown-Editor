# Markdown 工具栏布局与返回顶部

适用对象：基于上游 `v2.0.9` 的 `2.0.9-local.6` 候选。本文描述当前设计；实际安装和真实 IDE 验收以交付记录为准。

## 使用

1. 打开 Markdown 预览，点击右侧齿轮，再选择“自定义工具栏…”。
2. 在“已显示”区域拖动卡片排序，或聚焦卡片后使用 `Alt + 方向键` 移动；点击 `×` 隐藏项目。可在“未显示”区域点击项目重新添加。
3. 点击“应用布局”并等待成功；“恢复默认”也需应用后才保存。保存失败时保留草稿。设置入口固定保留，保存与取消按钮由编辑状态控制。
4. 新增的文字缩放按钮也可配置顺序；说明图片／Logo 可以隐藏、显示和排序。某些按钮在编辑或历史预览时会按模式隐藏。
5. “分屏编辑”和“所见即所得”在编辑时仍可直接点击切换；按钮若被隐藏，可在配置中重新添加。切换时保留未保存的草稿；转换无法保真时留在原模式并提示。

返回顶部采用上游浮动按钮：在预览中向下滚动后显示，可通过插件设置中的相关选项控制。它不是旧版主工具栏里的 `backToTop` 项目，也不再提供旧版私有返回顶部命令。

## 布局和保存

- 主工具栏的可配置项目位于横向滚动区，设置齿轮固定在右侧；滚动条占用空间时，齿轮与按钮行顶部对齐。
- 布局使用当前 IDE 的 `ExtensionContext.globalState` 保存。仅当新存储尚无数据时读取旧设置 `xlsxViewer.md.toolbarLayout`，读取不会直接覆盖原值。
- 等待实际状态写入成功后才应用；失败保留草稿。修复消除了对旧配置键可写的直接依赖，但不能据此断言旧 Cursor 窗口为何未注册该键。
- 同一 Extension Host 的保存串行，并比较布局摘要；不同进程／窗口不具备跨进程原子比较保证。不同 IDE 默认不共享布局。
- 没有有效布局时兼容旧的 `md.moveMdButtonsToEnd`。未知项目 ID 会保留但不渲染；损坏或未知版本使用默认显示，不自动覆盖原数据。用户明确应用后才写入。
- 旧版保存的 `backToTop` ID 作为未知项保留，不再生成旧按钮；上游浮动按钮独立工作。

## 实现和扩展

| 层 | 职责 |
| --- | --- |
| `src/shared/mdToolbarLayout.ts` | 稳定项目 ID、默认顺序、保护项目和模式约束 |
| `src/shared/mdToolbarStorage.ts` | 扩展状态读取、旧配置回退、摘要比较和串行保存 |
| `src/webviews/md/mdToolbarController.ts` | 原按钮节点排序、显隐、草稿面板及键盘／拖动交互 |
| `src/webviews/md/mdWebview.ts` | 上游按钮动作、编辑模式和设置入口 |
| `src/mdEditorProvider.ts` | 存储回执与同一宿主中的布局更新广播 |

新增可配置项目时，在上游动作接入后登记稳定 ID、节点、文案和模式约束，测试默认布局、旧布局补项、隐藏、顺序和编辑状态。不要保存 HTML、脚本或任意可执行命令。

## 验证与回退

齿轮对齐和保存失败处理已在隔离浏览器及存储测试中覆盖；浏览器消息使用模拟宿主，不能证明 Cursor 或 Antigravity 中的真实落盘。真实验收应检查窄分栏有滚动条、隐藏／排序后应用、关闭文档并重新打开、状态恢复，以及失败时草稿保留。

保留旧 VSIX 和配置备份。回装旧版不会自动恢复被覆盖的文档，也不保证旧版读取新版扩展状态；应分别核对布局与用户文件。
