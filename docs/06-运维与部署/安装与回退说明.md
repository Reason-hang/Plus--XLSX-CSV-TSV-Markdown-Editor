# 安装与回退说明

适用对象：`2.0.7-local.1` 候选。最终可用的 VSIX、哈希、安装和运行状态以本轮交付记录为准。

## 构建和验证

在源码仓库根目录执行 `npm run package` 和 `npm run test:local`，再用 VSIX 打包工具从同一份已验证源码构建安装包。打包后核对包内版本、扩展 ID、必需资源和 SHA-256；若源码或资源又发生变化，重新构建和验证。

主题构建是独立步骤：首次在 `themes/markdown-theme/` 根据锁文件安装依赖；修改主题 Less 后，在仓库根目录运行 `npm run theme:build`。无需为普通的插件构建重写主题产物。

`npm test` 需要用户明确授权启动隔离测试窗口，并通过 `VSCODE_EXECUTABLE_PATH` 指定已有 IDE；未提供时测试配置直接停止，不自动下载或升级 IDE。

## 安装 VSIX

在目标 IDE 的命令面板选择 `Extensions: Install from VSIX...`，选择已核验的 VSIX。候选包沿用扩展 ID `muhammad-ahmad.xlsx-viewer`，会替换该 IDE 中同 ID 的版本。

- Cursor 与 Antigravity 分别安装、分别核验；请区分 Antigravity IDE 与同名的其他应用。
- 安装成功与当前窗口加载新版是不同事实。是否重载由用户在合适时机决定；不得自动退出、重启或重载正在使用的 IDE。
- 保留旧版 VSIX 与哈希作为回装依据；不直接把解压目录复制到扩展目录。

Markdown 向下滚动后，上游浮动按钮可返回顶部；齿轮 → 自定义工具栏用于排序和显隐。自动保存需在插件设置内单独启用。详见 [工具栏说明](../04-开发文档/Markdown工具栏布局与返回顶部.md) 和 [个人维护说明](../../README-LOCAL-PATCH.md)。

## 外置主题

可在各 IDE 的用户设置中分别配置同一份本地 CSS：

```jsonc
{
  "xlsxViewer.md.theme.enabled": true,
  "xlsxViewer.md.theme.cssFile": "/仓库绝对路径/themes/markdown-theme/dist/markdown-theme.css",
  "xlsxViewer.md.theme.manifestFile": "/仓库绝对路径/themes/markdown-theme/dist/theme-manifest.json",
  "xlsxViewer.md.theme.watch": true
}
```

路径需替换为本机实际绝对路径。MPE 适配方式见 [主题说明](../../themes/markdown-theme/README.md)。轻量颜色和字号也可在插件设置的“外观”中调整，无须启用外置主题。

## 回退与排查

| 现象 | 处理 |
| --- | --- |
| 需要退回旧版 | 在同一 IDE 安装已核验的旧 VSIX，按用户选择的时机加载 |
| 主题无效果 | 核对 enabled、绝对路径、构建产物和主题状态输出 |
| 外部图片不显示 | 检查可信目录设置、真实路径和远程图片开关 |
| 保存提示外部修改 | 保留当前草稿，先比较磁盘版本并处理冲突 |
| 布局无法恢复 | 区分 IDE、已加载版本和扩展状态，勿以模拟测试替代真实落盘证据 |

回装扩展只能替换代码，不会修复已经被覆盖的源文件；恢复用户数据需依靠备份或有效的版本快照。
