## 使用说明

本索引是仓库文档的统一入口。根目录 README 用于快速了解项目，README-LOCAL-PATCH 用于安装和日常维护，docs 目录用于记录产品边界、架构、迁移、开发、测试和运维事实。

文档中的版本、配置名、命令名和路径以当前源码、package.json、构建产物与验证结果为准。历史变更只在 CHANGELOG 中保留，不作为当前功能事实。

## 文档维护规则

1. 新增长期文档优先放入对应的 docs 分域目录，并在本索引登记。
2. 根目录 README 和 README-LOCAL-PATCH 保留为发布入口，不在 docs 中复制全文。
3. 内部文档链接使用相对路径，不写本机用户目录。
4. 当前事实、历史事实和待验证事项必须分开描述，不把旧版本说明当作当前能力。
5. 主题生成报告属于生成物，修改主题源码后重新生成，不手工维护 CSS、manifest 和审计结果。
6. 变更版本号时同步更新 [版本记录表](./07-版本与发布/版本记录表.md)；记录中没有证据的字段必须写“待补证”。
