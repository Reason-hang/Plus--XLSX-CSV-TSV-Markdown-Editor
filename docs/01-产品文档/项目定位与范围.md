## 项目定位

本项目是基于上游 muhammad-ahmad.xlsx-viewer v1.9.97 的个人侧载 Fork，当前扩展版本为 1.9.98-local.6。目标是在保留 XLSX、CSV、TSV 和 Markdown 原有编辑能力的前提下，补充可迁移、可维护的 Markdown 外置主题能力。

扩展仍沿用上游扩展标识 muhammad-ahmad.xlsx-viewer。因此本地 VSIX 与同标识的官方扩展不能并存，安装本地包会替换当前 IDE 中的同标识版本。

## 当前交付范围

| 领域 | 当前能力 |
| --- | --- |
| XLSX、CSV、TSV | 保留原有查看、编辑、格式化、转换和保存链路 |
| Markdown | 保留编辑、预览、分栏、目录、同步滚动和保存能力 |
| mark 标签 | 预览中默认使用 #FF4E00 橙色背景，不强制黑字或加粗 |
| 外置主题 | 使用一份 Less 源码编译为单一 CSS，由本扩展加载 |
| MPE 兼容 | MPE 通过适配层加载同一份已编译 CSS |
| 迁移审计 | 扫描 MPE style.less，提示选择器和 @import 的人工处理项 |

## 明确不在范围内

- 不自动发布到 VS Code Marketplace 或 Open VSX。
- 不修改上游 Publisher、扩展标识或官方扩展的线上包。
- 不自动改写用户已有的 Markdown 正文或 MPE style.less。
- 不把 Less 编译器放进运行时 Webview。
- 不因主题增强重构 XLSX、CSV、TSV 的业务和数据处理逻辑。
- 不把三 IDE 的自动安装当作已完成的真实验收。

## 验收目标

核心目标是“一份主题源、一次编译、两个预览器消费”。用户只维护 themes/markdown-theme/theme.less 和其 partial，Markdown 正文只写 mark 标签，主题错误或路径错误不会让 Markdown 预览白屏，也不应影响 XLSX、CSV、TSV。
