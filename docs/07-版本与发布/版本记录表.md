## 版本详情

### v1.9.98-local.6

- 本次最重要变化：选中 Markdown 文本后按 `⌘ Command + ⌥ Option + ⇧ Shift + 3`，立即生成 `<mark>选中文本</mark>`。
- 新增：原生 Markdown 编辑器和插件 `Split Edit` 左侧编辑区的重点高亮快捷键；Windows/Linux 对应 `Ctrl + Alt + Shift + 3`。
- 修改：右侧预览沿用统一 `<mark>` 样式，左侧编辑后实时显示橙色高亮。
- 修复：无独立故障修复。
- 删除：无。
- 受影响功能：Markdown 编辑、分栏预览、快捷键。
- 数据与文件影响：仅向当前选区写入标准 HTML `<mark>` 标签；不写入内联 `style`，不影响其他 IDE 阅读。
- 提交 SHA：`b9d5950df1102513f61620db4dbf4ceb4af170ad`。
- 验证与交付：构建、类型检查、安全验证、主题验证、快捷键验证、文档验证通过；真实 VS Code、Cursor、Antigravity 交互验收待补。

- 修复：修复预览错误使用浅色变量、深色主题下表头文字不可见的问题。

## 维护规则

1. 每次变更版本号时，同步更新“版本总览”和对应“版本详情”。
2. 新增、修改、修复、删除四项必须全部出现；没有时写“无”。
3. 提交 SHA 必须可由 Git 验证；多个提交时列出承载主要功能的提交，并说明原因。
4. 自动化验证、真实 IDE 验收和安装包交付必须分别写明，不能合并表述为“已验证”。
5. `CHANGELOG.md` 保留技术变更历史；本文件负责版本、用户影响、文件影响和交付证据的统一台账。
