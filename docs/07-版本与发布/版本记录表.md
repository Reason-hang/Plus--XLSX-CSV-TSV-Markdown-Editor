## 字段说明

| 字段 | 填写规则 |
| --- | --- |
| 版本 | 与 `package.json` 或上游 Tag 保持一致 |
| 状态 | 当前、历史、上游基线或待补证 |
| 本次最重要变化 | 用一句用户能理解的话说明该版本的核心价值 |
| 新增、修改、修复、删除 | 分类记录；没有对应事项时写“无” |
| 受影响功能 | 写明 XLSX、CSV、TSV、Markdown、主题、保存等具体模块 |
| 数据与文件影响 | 说明是否改写、迁移、兼容或影响用户文件；没有时写“无” |
| 提交 SHA | 填入实际承载该版本功能的 Git 提交；无证据时写“待补证” |
| 验证与交付 | 区分自动化验证、真实 IDE 验收和安装包状态 |

## 版本详情

### v1.9.98-local.11

- 版本发布日期：2026-09-19（本地发布候选）。
- 上一版本：`v1.9.98-local.10`。
- 本次最重要变化：把固定工具栏的布局单位从内层主工具栏改为外层 `.toolbar-wrapper`，使 Markdown 格式工具栏的真实高度纳入内容区避让计算。
- 修改：主工具栏和格式工具栏在 Sticky Toolbar 模式下作为同一固定头部堆叠；`ResizeObserver` 观测该布局宿主；进入/退出 Split Edit 与 Preview Edit 后使用下一帧回算高度。
- 修复：格式工具栏显示或换行时，`#content` 仍仅按主工具栏高度布局而覆盖第二行的缺陷。
- 深色表格：奇数行 `#161617`，偶数行 `#27272A`；外置 Less 主题同步提高单双行区分度。
- 数据与文件影响：不修改用户文件或配置；可覆盖安装 `.10`，降级 `.10` 仅恢复旧布局行为。
- VSIX 文件与 SHA-256：`release/muhammad-ahmad.xlsx-viewer-1.9.98-local.11.vsix`；`f641feb334cd036a9f4b80dd38985e6bbfe96f2ef6881daaa0c5f3c2a31b6f71`（VSIX 内文档不自引用自身哈希）。
- 验证与交付：自动化和验包结果见本次交付记录；真实 VS Code、Cursor、Antigravity 验收需安装 `.11` 并执行 `Developer: Reload Window` 后补证。

## 维护规则

1. 每次变更版本号时，同步更新“版本总览”和对应“版本详情”。
2. 新增、修改、修复、删除四项必须全部出现；没有时写“无”。
3. 提交 SHA 必须可由 Git 验证；多个提交时列出承载主要功能的提交，并说明原因。
4. 自动化验证、真实 IDE 验收和安装包交付必须分别写明，不能合并表述为“已验证”。
5. `CHANGELOG.md` 保留技术变更历史；本文件负责版本、用户影响、文件影响和交付证据的统一台账。
