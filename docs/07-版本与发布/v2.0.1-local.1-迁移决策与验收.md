## 已知限制与后续验收

1. **数据保真**：短期门禁只识别围栏与 Tab。无围栏的复杂 Markdown 仍可能被 DOM→Turndown 整页重排。真正无损的 Preview Edit 需要 source range 驱动的受限编辑，另立版本。真实保存测试只使用临时副本，核对文件前后 SHA、围栏、Tab 与未编辑区域逐字差异。
2. **目录导航**：找回用户样本文档后，在临时副本或只读预览中验证原第 95–106 行；重复／近似标题应明确拒绝误跳。左侧自绘大纲与外部、相对链接须分别回归。
3. **上游与旧版组合**：分别验收 `v2.0.1` 的语言切换、Mermaid、代码块、表格和 `.10` 的主题／图片安全边界。`.11`–`.16` 的工具栏、大纲和滚动修复尚未纳入，不能以本轮迁移声明其已保留。
4. **回退**：旧 `main` 提交 `7510a2cc745c857b8e8c767af6d1cc3ae31dd4b4` 和本机 `.10` VSIX 均保留。回装旧 VSIX 可以恢复旧代码；对已被 Preview Edit 改坏的文件，回装不能逆向修复，需要文件备份或版本历史。回装过程本轮未实测。

以后同步上游时，先固定目标 tag，复审本表每个功能是否已被上游覆盖；只迁仍有差异的补丁。构建、自动化、VSIX、真实 IDE 和远端发布分别留证，避免把代码合并当成验收完成。
